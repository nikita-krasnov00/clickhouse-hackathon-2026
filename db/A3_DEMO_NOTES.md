# A3 — Шпаргалка ведущего демо: накрутка звёзд в слайсе подтверждена

> Все цифры прогнаны живьём на нашем ClickHouse Cloud 2026-07-18/19 (слайс ~106М строк,
> полное покрытие звёзд в окне 2024-01-01..2024-07-01). SQL — в `db/a3_golden.sql` (Q1–Q7).

## Герои демо и их окна аномалий

### Герой 1 — `solidSpoon/DashPlayer` · окно **2024-05-15..2024-05-25** · StarScout p_fake=0.86
Обскурный китайский видеоплеер для изучения английского. Самый чистый фрод в слайсе.
- **5 звёзд за январь+февраль вместе → 1 377 за май** (рост на 2 порядка без инфоповода).
- Пик 300 звёзд 2024-05-17, второй горб 227 звёзд 05-22, медиана активного дня — 5.
- **Портфель фермы (Q3, убойный слайд):** толпа окна co-звездит обскурные китайские
  утилиты с лифтом 30–50x против органики grok-1: `unilei/aipan-netdisk-search` **50x**,
  `Spr-Aachen/Easy-Voice-Toolkit` 48x, `kangpeiqin/bilivideo_down` 46x,
  `buxuku/VideoSubtitleGenerator` 42x. Один пул аккаунтов обслуживает много клиентов.
- **Ферма «дневной смены» (Q6):** ночью по Китаю (18–23 UTC) звёзды умирают до
  8, 9, 6, 3, 11 в час — min-час = 6% от среднего (у органики 30%).
- **Инверсия возраста (Q2):** 86.5% звездивших в окне — аккаунты старше года
  (фон репо — 75.1%), моложе суток — 0.2%. Ферма продаёт СОСТАРЕННЫЕ аккаунты.

### Герой 2 — `deepseek-ai/DeepSeek-VL` · окно **2024-03-11..2024-03-17** · p_fake=0.78
Дрип-кампания «по квоте»: подпись — форма кривой и сериальное звездение.
- **Прямоугольник (Q5):** 217, 206, 192, 223, 192 звёзд/день — **5 дней подряд ≥50% пика**.
  У органики grok-1 такой день **один** (пик 20 150 → распад 9 403 → 4 704 → 1 861).
- **Сериальные звездильщики (Q4):** медиана толпы окна — **80 звёзд за полгода**
  (у толпы grok-1 — 15); **44.3% зазвездили 100+ репо** (органика — 12.6%);
  медиана активных дней 52 против 13.
- **Круглосуточная подача (Q6):** hourly CV 0.38 против 0.50 у органики — бот не спит.
- **Связка кампаний (Q7):** **15.3%** толпы окна зазвездили `Zejun-Yang/AniPortrait`
  в ЕЁ окне двумя неделями позже (у толпы grok-1 — 1.4%) → **лифт 10.7x**.
- Ко-старинг по лифту — кластер китайских CV-репо: `ELLA-Diffusion/ELLA` 28x,
  `Meituan-AutoML/VisionLLaMA` 24x, `BAAI-DCAI/Bunny` 22x.

### Герой 3 — `OpenInterpreter/01` · запуск **03-21..22** vs хвост **03-23..25** · p_fake=0.46
Контраст ВНУТРИ одного репо: настоящий запуск + докупленный хвост.
- Запуск (21–22 марта, анонс девайса): 370 + 894 звёзд, аккаунтов моложе недели — **2%**.
- Хвост (23–25 марта): 590 + 601 + 388 звёзд, моложе суток — **12.7%** против 2.5%
  фона репо (**x5**); моложе недели — до 16% в день. Классическая догрузка свежаком
  поверх органической волны.

### Подтверждены, в запасе
- `Zejun-Yang/AniPortrait` · окно 2024-03-27..2024-04-03 · p_fake=0.83 — 682 звезды в пик,
  моложе суток 6.3% против 2.1% фона, медиана толпы 63 звезды/полгода, 213 общих
  акторов с окном OI01.
- `lavague-ai/LaVague` · окно 2024-03-13..19 · p_fake=0.76 — всплеск слит с запуском
  (Show HN), по кривой похож на органику, но толпа выдаёт: медиана 61 звезда/полгода,
  36.2% со 100+ звёздами. Показывать как «сложный случай», не как главный.

### Контроль-органика — `xai-org/grok-1` (релиз 2024-03-17)
- 20 150 звёзд за один день 03-18 — **43.5% всех звёзд полугодия за сутки**, затем
  чистый экспоненциальный распад. Burst есть — фрода нет.
- Толпа: медиана 15 звёзд/полгода, one-and-done 7.8%, суточная волна часовых поясов (CV 0.5).

## Слайд «накрутка vs органика» (главный месседж)

| Сигнал | Органика (grok-1) | Накрутка (герои) |
|---|---|---|
| Форма кривой | 1 день пика, распад по экспоненте | Полка: 5 дней ≥50% пика (DeepSeek-VL) |
| Burst-ratio | 610x — burst НЕ доказывает фрод! | 56–89x |
| Толпа: звёзд за полгода (медиана) | 15 | 51–80 |
| Толпа: 100+ звёзд за полгода | 12.6% | 32–44% |
| One-and-done аккаунты | 7.8% (живые лурки) | 0.4–3.8% |
| Ко-старинг | трендовые репо, лифт ~1–3x | портфель фермы, лифт 30–50x |
| Часы | суточная волна (CV 0.50) | конвейер 24/7 (0.38) или «смена» (0.66, ночь-0) |

**Твист для жюри:** наивный детектор «свежие пустые аккаунты» ловит только OI01;
у DashPlayer он показывает ровно наоборот (86.5% старше года, one-and-done 0.8%).
Фермы 2024 года маскируются камуфляжной активностью — и именно камуфляж
(сериальное звездение + общий портфель) становится отпечатком.

## Сюжет расследования (последовательность демо, по PLAN.md)

1. **Вопрос:** «Что странного со звёздами у solidSpoon/DashPlayer весной 2024?»
   → агент: timeline с anomalyWindow 05-15..25 (Q1). Инсайт: 5 звёзд за два месяца → 1 377 за май.
2. **Клик по пику 05-17 («почему?»)** → профиль толпы: гистограмма возраста (Q2) +
   стата «медиана 51 звезда/полгода, 31.8% со 100+ звёздами» (Q4).
3. **Drill «что ещё звездили эти аккаунты»** → leaderboard ко-старинга с лифтом (Q3):
   портфель китайских утилит 30–50x. Кульминация — network graph общих акторов.
4. **Контроль:** «А xai-org/grok-1 тоже накручен?» → timeline: пик 20 150 и распад,
   толпа-медиана 15, one-and-done 7.8% → вердикт-карточка: **органика, high confidence**.
5. **Финал:** verdict-card по DashPlayer: fraud, high confidence, evidence = 4 цифры
   (полка/портфель/сериальность/ночь-0), + Q7: те же руки в пяти несвязанных репо.

## Оговорки (чтобы не поплыть на вопросах жюри)

- «Возраст аккаунта» ≈ время от первого события актора В НАШЕМ СЛАЙСЕ до звезды.
  Для звездивших целевые репо в слайсе их полная Watch-история с 2011 — оценка честная.
- Полное покрытие звёзд по ВСЕМ репо — только в окне 2024-01-01..2024-07-01
  (фоновая часть слайса); все сравнения «толпа vs толпа» сделаны внутри этого окна.
- grok-1 вне окна 2024-01..07 в слайсе представлен только звёздами «наших» акторов —
  таймлайн grok-1 показывать в пределах окна.
- p_fake — из датасета StarScout (hehao98/StarScout, публичные списки fake-star
  кампаний); мы независимо подтверждаем сигнал в своём слайсе.

## Drill-каталог — предложение для A4

Имена параметров под selectionKeys контрактов: клик point → `{t, series}`,
клик row → ключевые колонки строки, клик cell → `{x, y}`.

| drillId | Параметры | Возвращает (ViewSpec) | SQL-эскиз |
|---|---|---|---|
| `stars-by-day` | `{repo, from?, to?}` | timeline + anomalyWindow | Q1: `count() GROUP BY toDate(created_at)`; окно — из каталога аномалий (Q5: дни ≥50% пика) |
| `actors-of-day` | `{repo, t}` (point на timeline; `t` = день, `series` = repo) | leaderboard акторов дня | `SELECT actor_login, счётчики за 6 мес (звёзды, активные дни, первый визит) WHERE repo_name={repo} AND toDate=…{t} ORDER BY stars_6mo DESC LIMIT 50` |
| `actor-age-profile` | `{repo, from, to}` (клик по anomalyWindow) | histogram бакетов возраста | Q2 с одним репо: бакеты `<1d/1w/1m/1y/1y+`, ряды WINDOW vs baseline |
| `co-starred-repos` | `{repo, from, to, order?=lift\|share}` | leaderboard с лифтом | Q3: suspects = толпа окна, control = толпа grok-1 марта (константа); `HAVING s_actors>=25 ORDER BY lift DESC LIMIT 20` |
| `costar-graph` | `{repo, from, to, maxNodes=30}` | graph: узлы-репо, рёбра-общие акторы | Q3 top-N по лифту → пары репо с `uniqExact(actor)` общих акторов ≥ порога |
| `actor-timeline` | `{actor}` (row в leaderboard, ключ `actor`) | timeline событий актора | `SELECT toDate(created_at), event_type, count() WHERE actor_login={actor} GROUP BY 1,2` + список репо дня |
| `hourly-heatmap` | `{repo, from, to}` | heatmap день×час (cell: `x`=час UTC, `y`=день) | Q6 разложить: `GROUP BY toDate(created_at), toHour(created_at)` |
| `burst-metrics` | `{repo}` | verdict/stat-карточка | Q5 с одним репо: max_day, медиана, burst_ratio, top_day_share, days_above_half_peak |
| `one-and-done` | `{repo, from, to}` | stat + histogram активности толпы | Q4 с одной группой: one_and_done_share, медиана звёзд/полгода, доля 100+ |
| `window-overlap` | `{repoA, repoB}` | stat/graph-ребро | Q7 для пары окон + лифт против контроля grok-1 |
| `cell-actors` | `{repo, x, y}` (cell в heatmap) | leaderboard акторов часа | как `actors-of-day`, но `toDate=…{y} AND toHour=…{x}` |

Замечания для A4:
- Q4/Q3 — самые тяжёлые (~3–4 s на admin): для бюджета «drill ≤300 мс» материализовать

  и `daily_stars` (repo, day → stars) — тогда все дриллы становятся lookup+join по маленьким таблицам.
- Окна аномалий героев можно захардкодить в каталог (см. таблицу героев) — агент
  их «находит», drill подсвечивает мгновенно.
- Контроль grok-1 (42 263 актора марта) — константный набор: положить в scratch
  однажды и переиспользовать во всех lift-запросах.
